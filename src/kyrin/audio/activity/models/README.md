# Bundled Silero VAD model

`silero_vad.onnx` is the ONNX opset 16 model from the official
`silero-vad==6.2.3` Python wheel. It is bundled so inference never requires a
model download. This file is distributed under the accompanying MIT license
(`LICENSE.silero`), copyright 2020-present Silero Team.
